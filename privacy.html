Privacy Policy

Last updated: October 23, 2026

This policy covers this website and the "TBTF Analytics" application used internally by the Too Broke To Fail YouTube channel.

This website

This site is a static page hosted on GitHub Pages. It has no sign-up, no forms, no cookies and no analytics of its own. GitHub may log standard request data (such as IP addresses) as described in GitHub's privacy statement.

TBTF Analytics

TBTF Analytics is a private tool used only by the owner of the Too Broke To Fail channel to read that channel's own YouTube statistics. It requests read-only access (YouTube Data API: youtube.readonly; YouTube Analytics API: yt-analytics.readonly) to the channel owner's own account.

  • What it reads: channel and video details and aggregate analytics (views, watch time, retention, traffic sources) for the owner's channel only.
  • What it does not do: it cannot upload, edit or delete anything, and it does not access any other person's data.
  • Storage: the access token and reports are stored only on the channel owner's own computer. Nothing is sold, shared or transferred to third parties, and the data is not used for advertising.
  • Google API Services: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions. Stored data can be deleted on request.
